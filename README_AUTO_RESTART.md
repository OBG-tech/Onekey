# 🔄 自动定时重启服务

## 功能说明

`auto_restart.sh` 脚本可以定时自动重启服务，防止因内存泄漏导致系统崩溃。这是一个临时缓解措施，建议配合根本性的内存泄漏修复使用。

## 使用方法

### 基本用法

```bash
# 使用默认配置（每2小时重启一次）
./auto_restart.sh

# 自定义重启间隔（例如每3小时重启一次）
./auto_restart.sh 3

# 指定端口（默认8082）
./auto_restart.sh 2 8082
```

### 参数说明

- **第1个参数**: 重启间隔（小时），默认 2 小时
- **第2个参数**: 服务端口，默认 8082

## 功能特性

✅ **定时重启**: 按设定间隔自动重启服务  
✅ **服务监控**: 检测服务异常停止并自动重启  
✅ **自动录音**: 启动时自动开启麦克风录音功能 🎤 **新增**  
✅ **优雅退出**: 支持 Ctrl+C 优雅停止  
✅ **日志记录**: 所有操作记录到 `auto_restart.log`  
✅ **倒计时显示**: 每10分钟显示剩余时间

## 示例场景

### 场景1: 长时间直播（推荐每2小时重启）
```bash
./auto_restart.sh 2
```

### 场景2: 短时间测试（每30分钟重启）
```bash
./auto_restart.sh 0.5
```

### 场景3: 稳定运行（每4小时重启）
```bash
./auto_restart.sh 4
```

## 日志文件

脚本会生成两个日志文件：

- `auto_restart.log`: 重启操作日志
- `service_output.log`: 服务输出日志

### 查看实时日志

```bash
# 查看重启日志
tail -f auto_restart.log

# 查看服务输出
tail -f service_output.log
```

## 停止自动重启

按 `Ctrl+C` 即可停止脚本并优雅关闭服务。

## 注意事项

⚠️ **临时方案**: 这是一个临时缓解措施，建议尽快应用根本性的内存泄漏修复  
⚠️ **数据丢失**: 重启会清空内存中的缓存数据（如转写记录、关键时刻等）  
⚠️ **服务中断**: 重启过程中会有几秒钟的服务中断

## 配合使用建议

1. **短期**: 使用此脚本定时重启，避免内存耗尽
2. **长期**: 应用内存泄漏修复补丁（见 `implementation_plan.md`）
3. **监控**: 定期查看日志，了解系统运行状况

## 系统要求

- Linux/macOS 系统
- Bash shell
- 已安装的依赖：`lsof`, `pkill`, `pgrep`

## 故障排查

### 问题1: 脚本无法启动服务
**解决**: 检查 `start_live.sh` 是否可执行，确保虚拟环境已安装

### 问题2: 服务频繁重启
**解决**: 检查 `service_output.log`，查看服务启动失败的原因

### 问题3: 端口被占用
**解决**: 更改端口号或手动释放端口 `lsof -ti:8082 | xargs kill -9`
